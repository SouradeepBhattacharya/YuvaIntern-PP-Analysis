# YuvaIntern PP analysis

Author: Souradeep Bhattacharya

Reproducible educational models supporting SAP PP internship assignments: material requirements, deterministic capacity comparisons, forecasting, production scheduling, Monte Carlo experiments and illustrative performance trends.

All operational inputs are hypothetical. This project does not claim live SAP configuration or transaction execution. Results are analysis examples, not measured business outcomes.

Run `python -m pip install -r requirements.txt` and then `python portfolio_analysis.py`. Figures and JSON results are written to `output/`.

The simulation uses 2,000 replications, seed 20261002 and common random inputs across capacity alternatives. Assumptions and limitations are documented in the associated internship reports.
